IDECO WEB HUB v3.6 – CÀI THÀNH ỨNG DỤNG FULL MÀN HÌNH (ANDROID + IOS)

BẢN GỐC: APP CHUẨN IDECO HUB.zip (IDECO WEB HUB v3.5) do anh gửi.
CẬP NHẬT: Thêm menu 📝 ĐỀ XUẤT & DUYỆT → https://duocphamideco.github.io/duyetvanban-mobile/
Menu mới tự thêm vào danh sách đã lưu trên điện thoại/máy tính, không làm mất các menu đã thiết lập.
Mặc định menu mở trong IDECO HUB; nếu trang ngoài chặn nhúng, bấm "MỞ TRỰC TIẾP".

CƠ CHẾ CHUẨN THAM KHẢO: HUYỀN TRỢ LÝ (manifest.json + sw.js + các icon ở thư mục gốc).
LOGO: dùng chính ảnh LOGO(2).png anh gửi, không thay thế thương hiệu.

BƯỚC 1: Sao lưu index.html cũ trong repository đang chạy IDECO WEB HUB.
BƯỚC 2: Giải nén ZIP. Chọn TẤT CẢ 11 file trong ZIP (bao gồm tệp hướng dẫn này nếu muốn lưu) (không kéo nguyên ZIP), tải vào ĐÚNG THƯ MỤC đang có index.html của IDECO WEB HUB trên GitHub.
BƯỚC 3: GitHub → Add file → Upload files → chọn file, xác nhận ghi đè file cũ (nếu có) → Commit changes.
BƯỚC 4: Chờ GitHub Pages triển khai, mở: https://<website-hub-cua-anh>/pwa-check.html
       Các mục HTTPS, manifest.json, logo và service worker phải OK khi mở trang chính.
BƯỚC 5: Xóa biểu tượng lối tắt cũ trên điện thoại nếu đang có; mở lại trang IDECO WEB HUB bằng Chrome Android, vào menu ⋮ → "Cài đặt ứng dụng" (không phải "Tạo lối tắt").
       Mở từ biểu tượng màn hình chính. Bản cài đúng chạy standalone, KHÔNG hiển thị ô địa chỉ web.
BƯỚC 6 (iPhone): mở bằng Safari → Chia sẻ → Thêm vào Màn hình chính → bật "Mở dưới dạng ứng dụng" nếu Safari có tùy chọn.

CẤU TRÚC ZIP (các tệp phải nằm cùng cấp):
    index.html, manifest.json, sw.js, icon-192.png, icon-512.png,
    icon-maskable-192.png, icon-maskable-512.png, apple-touch-icon.png,
    favicon-48.png, pwa-check.html.

LƯU Ý:
- Các file manifest.webmanifest và biểu tượng v3.4 cũ có thể giữ nguyên nhưng không còn được sử dụng vì index.html mới chỉ tham chiếu manifest.json.
- Nếu GitHub Pages trỏ nhầm repository / nhầm thư mục, hoặc chưa tải đầy đủ các file, Chrome sẽ chỉ tạo shortcut có thanh địa chỉ; không có cách ép shortcut thành ứng dụng chỉ bằng HTML.
- Các ứng dụng/web bên ngoài mở ra khỏi IDECO WEB HUB có thể chuyển qua trình duyệt: "standalone" chỉ áp dụng trong phạm vi của PWA.
- Service worker chỉ quản lý shell WEB HUB; không lưu cache dữ liệu ERP, Firebase, AI, ứng dụng khác.
- Giữ nguyên logic đăng nhập, localStorage, các menu cũ và thao tác mở ứng dụng.
