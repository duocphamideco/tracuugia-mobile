TẢI LÊN GITHUB (repo duocphamideco/tracuugia-mobile, thư mục gốc — không tạo thư mục bao ngoài)
1. index.html             → thay bản hiện tại
2. manifest.webmanifest   → thay
3. sw.js                  → thay (phiên bản v3)
4. offline.html           → giữ / thay đều được
5. Thư mục icons/ (6 ảnh) → tải lên, giữ đúng tên thư mục "icons"
6. pwa-install.js         → không còn dùng, có thể xóa

Chờ GitHub Pages cập nhật (1–2 phút), mở lại trang và tải lại (kéo xuống / F5).

CÀI TRÊN ĐIỆN THOẠI
• Android: Chrome → https://duocphamideco.github.io/tracuugia-mobile/ → ⋮ → "Cài đặt ứng dụng".
• iPhone: Safari → cùng địa chỉ → Chia sẻ → "Thêm vào MH chính" → "Thêm".
• Máy đã thêm biểu tượng cũ (không có logo): xóa biểu tượng cũ rồi cài lại.
